Privacy policy

Last updated: October 10, 2026

OrpheusEngine is a private tool that one creator runs on their own computer to publish videos to their own YouTube channel. This page explains what data it accesses and what it does with it.

What it accesses

When the channel owner authorizes it with their Google account, OrpheusEngine uses YouTube API Services with two permissions:

  • Manage your YouTube account, to upload the owner's videos, set thumbnails, add videos to playlists and schedule publication;
  • View YouTube Analytics reports, to read the channel's own statistics (views, watch time, retention, subscribers).

It does not access any other Google service, and it does not access data from any other user or channel.

How the data is used and stored

  • The access token is stored only on the owner's computer. There is no server and no database outside that computer.
  • Analytics data is used only to plan the channel's next videos.
  • No data is sold, shared with third parties, or used for advertising.

OrpheusEngine's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

OrpheusEngine uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and your data is also covered by the Google Privacy Policy.

How to revoke access

Access can be revoked at any time from the Google account permissions page. Deleting the token file from the owner's computer also ends access.
